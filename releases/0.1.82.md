# Cindx 0.1.82

This release adds a fail-closed Auto-to-Pro learning path and broadens Aliyun
speech recognition support. It does not claim a measured intelligence uplift or
Fugu Ultra parity; promotion still requires real, independent evidence.

## Auto-to-Pro learning

- Qualified completed Auto workflows can become bounded teacher cases with
  prompt, task-graph, model, outcome, provenance, and usage evidence.
- Pro evaluates current and challenger profiles against the same Auto outcome
  with position-balanced blind comparisons and an evaluator independent from
  the compared workflow models.
- Auto-transfer evidence is isolated from ordinary GEPA evidence. A Pro profile
  can be promoted only when both gates pass against the pinned stable Auto
  profile; incomplete, unsafe, inconsistent, or stale evidence fails closed.
- Pro mutation reserves reflection capacity for Auto-transfer observations, so
  archived teacher evidence participates in improvement rather than remaining
  passive telemetry.
- The foreground agent path adds no model calls. Learning and comparison remain
  background work with frozen dataset and evidence digests.

## Product and providers

- Cindx Pro is described as `Learns from Auto and continuously improves`.
- The provider catalog now uses the English name `Aliyun Dashscope`.
- Voice settings use general speech-recognition semantics and expose both
  `qwen3-asr-flash-realtime` and `fun-asr-realtime`.
- Fun-ASR uses the DashScope task WebSocket protocol with PCM16 16 kHz input,
  ordered partial/final transcript handling, bounded output, and explicit task
  completion.
- The ASR implementation is split into transport, task-protocol, guard, and
  configuration modules, each enforced by the desktop structure gate.
