# Cindx 0.2.77

This release completes the phase-3 agent-core rebuild: run preparation now
plans purely by effort tier with no planning model call, and the retired
workflow/conductor/GEPA machinery has been physically removed from the tree.

## Effort-tier planning

- Run preparation builds a deterministic `EffortRunPlan` from the effort tier
  (`plan_effort_run` + `effort_tier_model`) with no planning/conductor model
  call. Fast, Auto, and Pro differ by budget, knowledge defaults, and
  verification strength, not by a learned route.
- The knowledge decision (durable-memory recall + workspace retrieval) is part
  of the effort plan; Fast skips both, Auto/Pro recall relevant memory keyed on
  the bounded run prompt and retrieve workspace context.
- The conductor/strategy planning surface (`agent_strategy_*`,
  `agent_conductor_*`, conductor health, workflow routing) is deleted.

## Removed machinery

- The prompt-genome / prompt-profile mechanism (a GEPA remnant with no shipping
  behavior consumer) is removed from the desktop crate and the orchestrator.
- The `realworld-eval` harness (module, cargo feature, and binary) is removed
  from the product build; the surviving memory-effect contract is retained.
- The desktop crate no longer depends on the `orchestrator` crate; the
  planning/knowledge/learning-evidence types it used now live in `agent-core`.
  `orchestrator` survives only as a dependency of the non-shipping
  `orchestrator-eval` crate.

## Verification

- Deterministic suite green at every layer: desktop default-feature tests,
  workspace tests, Rust formatting and strict Clippy, and the control-plane
  quality-gate profile.
- This is a deterministic refactor; it establishes no answer-quality,
  intelligence-uplift, Auto/Pro superiority, or Fugu-parity claim.
