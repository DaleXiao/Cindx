# Cindx 0.1.97

This is the deliverable release for the 13A grounded-completion repair. It also
updates the transitive build dependency `undici` from `6.27.0` to `6.28.0` so
the GitHub release dependency audit passes with zero known vulnerabilities.
The 0.1.96 local package was not used as the final GitHub package after that
audit blocker was found; no published tag was rewritten.

## Agent contract repair

- Compound execution intent recognizes later create, update, and run steps
  without granting mutation semantics to guidance, denials, summaries, quoted
  commands, code fences, compound nouns, or unrelated Chinese phrases.
- Local source clauses bind to named workspace inputs. Generic web, upstream,
  remote, URL, and third-party sources remain explicit external obligations.
- Target anchors remain only in active evidence domains, so a local JSON field
  such as `sources` cannot invent an external-grounding requirement.
- Genuine external research still requires external evidence; workspace and
  shell receipts still cannot satisfy it. The completion gate was not relaxed.
- The literal-aware segmenter uses a bounded one-pass scan over borrowed
  slices, with no added model call, network request, regular expression, or I/O.

## Evidence boundary

The frozen 13A repair calibration ran two tool-using cases across Fast, Auto,
and Pro once each. All six completed with 7/7 deterministic checks and no
safety violation. The previously blocked long-horizon case completed in every
treatment with lower latency, tokens, model calls, tool calls, and recoveries
than its matched 0.1.94 pilot cell.

This permits expansion of the frozen matrix only. It does not prove statistical
significance, general intelligence uplift, Auto or Pro superiority, or Fugu
parity. See the complete
[13A repair calibration](../docs/evaluations/CINDX_AGENT_REALWORLD_13A_REPAIR_0.1.95_2026-08-04.md).
