# Cindx 0.1.81

This release integrates Agent Core Goals 1-5 and records their current evidence
boundary. It does not claim Fugu Ultra parity or a proven intelligence uplift.

## Runtime and architecture

- `agent-application` owns the production run/reprepare driver and terminal
  delivery contract.
- Auto and Pro use validated conductor decisions and evidence-led task-graph
  assignments without forcing different models onto unrelated roles.
- Context, workspace retrieval, graph expansion, and durable memory preserve
  provenance and avoid mutating canonical conversation history.
- GEPA promotion remains outside active runs and requires paired plus holdout
  evidence before a profile can become active.
- The production desktop enables LanceDB explicitly; a light Rust build excludes
  LanceDB, Arrow, and DataFusion for boundary and dependency checks.

## Provider-backed Agent diagnostic

The maintained Pilot v2 runner executed 12 real-provider runs over three frozen,
read-only workspace tasks and four treatments. All runs delivered, with zero
provider errors and zero safety violations.

| Treatment | Mean quality | Median latency | Tokens |
| --- | ---: | ---: | ---: |
| Direct answer-quality ceiling | 1.000 | 8.0s | 1,477 |
| Fast | 0.417 | 6.8s | 25,877 |
| Auto | 1.000 | 62.4s | 82,355 |
| Pro | 0.333 | 102.2s | 108,450 |

Auto matched the direct answer-quality ceiling in this small matrix, but at
`7.83x` median latency and `55.76x` tokens. Fast and Pro regressed in answer
completeness. No frozen GEPA profile was active. This is a directional diagnostic
and a `NO-GO` for a collaboration-uplift claim, not a statistically powered
ranking. See the [sanitized report](../docs/evaluations/CINDX_AGENT_REALWORLD_LITE_G6_0.1.80_2026-08-01.md).
