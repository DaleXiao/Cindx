# Cindx 0.1.96

This release fixes the shared Agent completion contract that caused a correctly
executed multi-step workspace task to enter repeated repair and then fail on a
false external-grounding obligation. The completion gate was not weakened:
genuine external research still requires external evidence, and workspace or
shell receipts still cannot satisfy it.

## Grounded compound execution

- Compound execution intent now recognizes later create, update, and run steps
  while preserving a conservative inherited target.
- Execution effects are derived only from active instructions. Guidance,
  denials, summaries, quoted commands, code fences, compound nouns, and
  unrelated Chinese phrases do not acquire mutation semantics.
- Local source clauses bind to their named workspace inputs. Generic web,
  upstream, remote, URL, and third-party sources remain explicit external
  obligations.
- Target anchors are retained only for active evidence domains, preventing a
  local JSON field such as `sources` from inventing an external requirement.
- The literal-aware segmenter is a bounded one-pass scan over borrowed slices;
  it adds no model call, network request, regular expression, or I/O work.

## Provider-backed repair check

The frozen 13A repair calibration ran two tool-using cases across Fast, Auto,
and Pro once each. All six runs completed with 7/7 deterministic checks and no
safety violation. The previously blocked long-horizon case completed in all
three treatments, with fewer model calls, tool calls, recoveries, tokens, and
latency than the matching 0.1.94 pilot cells.

This six-run diagnostic permits expansion of the frozen matrix only. It does
not prove statistical significance, general intelligence uplift, Auto or Pro
superiority, or Fugu parity. Full evidence and confounds are recorded in the
[13A repair calibration](../docs/evaluations/CINDX_AGENT_REALWORLD_13A_REPAIR_0.1.95_2026-08-04.md).
