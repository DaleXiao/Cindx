# Cindx Dynamic Collaboration V1 Frozen Protocol

## Status

`PROTOCOL_ONLY`. No provider result is included in this document.

This experiment tests one narrow question: does a Conductor-owned executable
Workflow add measured product value over the matched Grounded Direct path after
the route decision and workflow graph have been unified into one provider
response?

It does not test GEPA, durable-memory benefit, broad Agent intelligence, or Fugu
Ultra parity. The suite was used by an earlier reliability diagnosis, so this is
a mechanism calibration on frozen route-blind tasks rather than unseen
generalization evidence.

## One-Shot Rule

The candidate code and this protocol are committed before provider execution.
The full matrix is executed once. A timeout, setup failure, schema failure,
missing receipt, Direct selection, or failed check remains in the denominator.
There is no per-case prompt edit, profile mutation, replacement cell, discarded
run, or result-driven rerun.

## Admission Gates

All gates are conjunctive:

1. All eight cells are retained and structurally valid; provider evidence is
   complete, all six product cells have strategy receipts, and safety violations
   equal zero.
2. Both Grounded Direct cells complete, pass every quality and external-effect
   check, and therefore remain a valid non-regression control.
3. Auto and Pro do not regress matched completion, quality, external effects, or
   safety against Grounded Direct.
4. At least one Auto or Pro cell selects and executes Workflow. Every Workflow
   cell must bind `workflow_plan_source=run_decision`, the exact proposal and
   materialized-plan digests, distinct root roles, one final synthesis, and a
   completed workflow receipt. Independent verification must be present when
   requested and must feed the final synthesis.
5. At least one matched Auto or Pro cell converts a Grounded Direct quality or
   completion failure into a pass. Equal quality is not incremental value.
6. Auto remains within `3x` Grounded Direct median latency and `4x` total tokens.
   Pro remains descriptive but must stay within `6x` latency and `8x` tokens.

## Decision

- `GO_INCREMENTAL_VALUE` requires every gate above.
- `NO_GO_NOT_EXERCISED` applies when no eligible Workflow executes.
- `NO_GO_NO_INCREMENT` applies when Workflow executes without a matched quality
  or completion win, even if every task passes.
- `NO_GO_REGRESSION` applies to any product quality, completion, safety, or
  resource regression beyond the frozen limits.
- `INVALID_EVIDENCE` applies to an incomplete matrix or inconsistent receipts.

Only `GO_INCREMENTAL_VALUE` supports a claim that dynamic collaboration adds
value on this frozen matrix. Every other outcome remains diagnostic and cannot
be promoted into a general intelligence claim.
